# Campus SOS — Project Overview

## 1. Project Description

Campus SOS is a campus emergency assistance application designed to help students request emergency support quickly and help designated responders manage those requests.

## 2. Project Objectives

* Provide a simple interface for requesting emergency assistance.
* Allow authorized responders to view and manage SOS alerts.
* Develop a responsive interface for desktop and mobile devices.
* Build a backend API to process application requests.
* Prepare the application for database integration.
